## Como executar localmente

Abra o arquivo `index.html` diretamente no navegador ou use um servidor estatico simples a partir da raiz do repositorio.

Exemplo com Python:

```powershell
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Publicacao

O projeto e publicado pelo GitHub Pages a partir da branch `main`, usando workflow oficial em `.github/workflows/pages.yml`.

O site nao depende de frameworks, Node.js ou etapa de build.
